# Amber Lantern Sessions II
Sets 3 e 4 — vídeos 03 e 04 do The Amber Lantern.
Cinquenta faixas instrumentais, vinte e cinco por vídeo.

> **Por que estes dois sets, e nesta ordem.** Os dados do vídeo 01 mostraram de onde
> veio a audiência: metade do cluster de RPG e videogame (Baldur's Gate, Elden Ring,
> Zelda) e metade do cluster de estudo (lofi hip hop radio). O Set 3 vai atrás do
> primeiro, o Set 4 do segundo. Não é variação estética — é ir buscar a audiência
> pelo nome que ela usa.

> **Como operar:** marque **Instrumental** e cole o bloco de estrutura no campo de
> letra mesmo assim. Se a faixa sair em 2m30, deixe: vinte e cinco faixas fecham a
> hora. Ao usar **Extend**, rode o **Get Whole Song** depois.

## Bloco de estrutura C — para o Set 3

```
[Intro - solo instrument, sparse]
[Theme A]
[Theme A - repeat with second instrument]
[Variation - quieter]
[Instrumental Solo]
[Theme B]
[Theme A - returns, fuller]
[Long Outro - fading, last notes ringing]
```

## Bloco de estrutura D — para o Set 4 (estudo)

```
[Intro - one figure, established]
[Theme A - repeated]
[Theme A - repeated, second instrument enters]
[Drift - same figure, thinner]
[Theme A - repeated again]
[Long Outro - the figure slowly stopping]
```

# O QUE ESTES DOIS SETS ESTÃO TESTANDO

Cada um mira um cluster que já provou existir no seu tráfego. Na sexta, compare os
dois entre si e com o vídeo 01:

- Se o **Vídeo 03** render mais, o canal é de RPG e você deve fundo nessa direção:
  mais séries de mesa, títulos com D&D, e vale abrir uma playlist só para isso.
- Se o **Vídeo 04** render mais, o canal é de foco e estudo — e o concorrente real
  não é a taverna medieval, é o lofi. Aí o formato pede três horas em vez de uma.
- Se os dois empatarem com o vídeo 01, o cluster não é o fator decisivo e o trabalho
  volta para capa e título.

Anote o resultado no documento de acompanhamento.
